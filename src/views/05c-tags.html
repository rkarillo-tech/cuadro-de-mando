☁️ Nube de etiquetas

Pon etiquetas con el botón ＋ Etiqueta de cada nota, tarea, tarjeta, evento o marcador (un desplegable con todas las tuyas), o escribe #etiqueta en el texto (al teclear # te sugiere las que ya usas). Cada etiqueta tiene su color: cámbialo aquí al elegirla o con el punto de color del desplegable. Con / puedes crear niveles: #proyecto/portal también aparece en #proyecto. Mayúsculas y tildes no cuentan: #Reunión = #reunion.
